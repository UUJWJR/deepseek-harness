# @deepseek-ai/dsh-client-ui-files

[English](README.md) | 中文

文件系统的浏览器文件树。它在侧边栏注册一个「文件」页脚操作，打开一个模态文件树 —— 面包屑、目录列表、显示隐藏文件开关与多选批量删除 —— 由宿主 `ctx.remote.files` Remote 驱动。它不注册任何面向模型的界面。

## 模型体验

无，浏览器文件树仅列举与删除文件而不改变模型上下文；宿主工具消费方拥有所有面向模型的效果。

#### KV Cache 影响

无；此包既不会组装也不会发送提供方请求。

## 已知限制与暂缓事项

- **从文件系统根开始** — 树从文件系统根打开；以工作区根为默认值暂缓。
- **无移动或拖拽** — 目前仅有浏览、选择与删除；移动与拖拽移动暂缓。
- **单层导航** — 树每次仅列出一个目录层级；浏览器通过连续列举调用组合出树。
