# @deepseek-ai/dsh-client-ui-tool-compact

[English](README.md) | 中文

紧凑工具调用胶囊。它绑定持久化 `compactMode` 设置，并在该设置开启时以回合级胶囊条替换完整工具调用树：一个 `ConversationNodeDefinition` 把一个回合中的所有工具调用聚合为一条（5 列上限 + "+N" 溢出），由 keyed 胶囊渲染器渲染，同时一个遮蔽渲染器隐藏调用树。设置 General 区域中的紧凑模式复选框行拥有该开关。它不注册任何面向模型的界面。

## 设置

| 命名空间 | 字段 | 默认 |
|---|---|---|
| `ui-tool-compact` | `compactMode` | `false` |

## 模型体验

无，紧凑渲染器仅投影已记录的工具调用而不改变模型上下文；面向模型的工具界面位于宿主工具包中。

#### KV Cache 影响

无；此包既不会组装也不会发送提供方请求。

## 已知限制与暂缓事项

- **无逐胶囊交互** — 条为只读；选择单个胶囊或展开某一工具的详情暂缓。
