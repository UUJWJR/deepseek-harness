# @deepseek-ai/dsh-client-ui-report

[English](README.md) | 中文

报告（展示区）能力的浏览器画廊。它在侧边栏注册一个「报告」页脚操作，打开一个模态画廊 —— 标签侧栏、报告列表与所选报告源预览 —— 由宿主 `ctx.reports` Remote 之上的单个 `ReportController` 驱动。它不注册任何面向模型的界面。

## 模型体验

无，浏览器画廊仅渲染持久化的报告记录而不改变模型上下文；宿主工具消费方拥有所有面向模型的效果。

#### KV Cache 影响

无；此包既不会组装也不会发送提供方请求。

## 已知限制与暂缓事项

- **画廊只读** — 浏览器界面只列举已发布报告并显示所选报告的源元数据，不提供发布、编辑或删除控件；发布通过宿主工具消费方进行。
- **无报告正文预览** — Remote 仅暴露 `list`/`tags`/`publish`，不暴露报告内容，因此预览显示源元数据而非所复制文件的正文。
