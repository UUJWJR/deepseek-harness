# @deepseek-ai/dsh-client-ui-report

[English](README.md) | 中文

报告（展示区）能力的浏览器画廊。它将宿主 `ctx.reports` 服务的已发布报告渲染为画廊，并拥有客户端报告视图组件与列表渲染。它不注册任何面向模型的界面。

## 模型体验

无，浏览器画廊仅渲染持久化的报告记录而不改变模型上下文；宿主工具消费方拥有所有面向模型的效果。

#### KV Cache 影响

无；此包既不会组装也不会发送提供方请求。

## 已知限制与暂缓事项

- **画廊只读** — 浏览器界面只列举与预览已发布报告，不提供发布、编辑或删除控件；发布通过宿主工具消费方进行。
