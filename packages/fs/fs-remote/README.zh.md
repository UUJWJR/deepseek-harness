# @deepseek-ai/dsh-fs-remote

[English](README.md) | 中文

浏览器侧文件系统 Remote：在 `ctx.fs` 之上暴露基于路径的 `list`/`delete`/`move`，使 Web GUI 能渲染文件树并应用变更。绝对路径走线传输；浏览器从不拼接路径段。

## 领域词汇

- **file entry（文件条目）** — 目录的一个子项：名称、绝对路径、类型与隐藏标志。
- **list（列举）** — 一个目录层级的子项。
- **delete（删除）** — 删除一个文件或一个空目录；非空目录以 `FS_NOT_EMPTY` 失败。
- **move（移动）** — 将一个路径重命名为另一路径；把目录移入自身后代以 `FS_LOOP` 失败。

## 模型体验

无，Remote 仅向调用方返回目录列表并应用变更；不注册任何面向模型的提示词、schema、工具或消息。

#### KV Cache 影响

无；此包既不会组装也不会发送提供方请求。

## 已知限制与暂缓事项

- **单层列举** — `list` 只返回一个目录层级；浏览器通过连续 `list` 调用组合出树。
- **无批量端点** — `delete`/`move` 每次作用于一个路径；浏览器把多选折叠为逐项调用（祖先折叠在 fs seam 中）。
