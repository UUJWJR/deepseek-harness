# @deepseek-ai/dsh-trusted-skill-window

[English](README.md) | 中文

可信技能权限窗口。当一个部署可信的技能运行时，本插件在 TTL 与硬上限约束下自动批准该技能的工具调用，且每笔授权仍由审批服务的审计对记录。

## 行为

窗口在显式的技能加载动作——一个指名 `trustedSkills` 中技能的 `skill` 工具调用——时打开，绝不依赖模型行为探测（ADR 0008）。当某会话的窗口打开时，`approval/request` 解析为 `allowed-once` 而非提示。窗口在过期（`windowTtlMs`）、会话结束（窗口按会话）或达到 `maxAutoApprovals` 笔授权后关闭。审批策略为 `never` 的会话在派发前即拒绝，因此窗口绝不会覆盖该确定性立场。

## 配置

| 键 | 默认 | 约定 |
|---|---:|---|
| `trustedSkills` | `[]` | 部署信任的技能名；加载其一即开窗。 |
| `windowTtlMs` | `600000` | 窗口生命周期，毫秒。 |
| `maxAutoApprovals` | `50` | 每个窗口最多自动批准的工具调用数。 |

## 模型体验

无，窗口在可信技能期间自动批准审批请求，但不注册任何面向模型的提示词、schema、工具或消息。

#### KV Cache 影响

无；此包既不会组装也不会发送提供方请求。

## 已知限制与暂缓事项

- **无交付边界关窗** — 窗口按 TTL、会话结束或硬上限关闭，而非按「技能完成」信号（harness 不暴露该信号）。
- **信任是部署级** — 部署内所有会话继承同一信任集；不支持按会话信任。
